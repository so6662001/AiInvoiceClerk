# 08 — 前端设计 (Vue 3)

## 1. 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3.4+ (Composition API) | 全面使用 `<script setup>` |
| 构建工具 | Vite 5 | 快速 HMR，构建优化 |
| UI 库 | Element Plus 2.x | 企业级 UI，完善的表格/表单/弹窗 |
| 状态管理 | Pinia 2 | 轻量、TypeScript 友好 |
| 路由 | Vue Router 4 | 嵌套路由、路由守卫 |
| HTTP | Axios + 请求/响应拦截器 | 统一错误处理、Token 刷新 |
| TypeScript | 5.x | 全面类型化 |
| 图表 | ECharts 5 | 税务看板可视化 |
| WebSocket | Socket.IO / 原生 WS | 开票进度实时推送 |
| PDF 预览 | PDF.js | 发票/合同在线预览 |
| 电子签名 | signature_pad | 手写签名组件（电子签章内嵌） |
| 国际化 | vue-i18n | 预留多语言能力 |

## 5. 性能优化

### 5.1 首屏加载

- 路由懒加载（每个页面独立 chunk）
- Element Plus 按需导入（unplugin-auto-import）
- CDN 加载大型库（ECharts, PDF.js）
- Gzip/Brotli 压缩
- 预连接 DNS Prefetch

### 5.2 列表页性能

- 虚拟滚动（大列表 > 100 条时启用）
- 分页加载
- 请求防抖（搜索输入 300ms 防抖）
- 骨架屏加载

### 5.3 状态管理

- Pinia 持久化（开票草稿自动保存到 localStorage）
- 表单数据离开页面前提醒保存
- 接口层缓存（SWR 策略：先返回缓存，后台刷新）
